# Eggonic — Message Content Intent: Feature Evidence

Two screenshots from a live server. All features shown require reading
message text and are configured per server, off by default.

**1. Message logging with content.** A message edit logged with its
before/after text and a jump button, and two deleted messages logged with
their content — one deleted by a moderator action, one deleted
automatically by the chat filter:

![Server log showing edited and deleted message content](02-message-content-logs.png)

**2. Chat filter enforcement.** A member's message containing a configured
banned word was deleted automatically and answered with a removal notice.
The server owner's identical message directly above it was deliberately
spared — owners and administrators are exempt from filters by design:

![Chat filter removal notice in the channel](03-chat-filter-notice.png)
